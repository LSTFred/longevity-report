Privacy Policy

Last updated: November 22, 2026

The Longevity Report Pipeline is an internal tool used only by the owner of The Longevity Report YouTube channel to upload and manage videos on that channel.

What data the tool accesses

With the channel owner's authorization, the tool uses the YouTube Data API to upload videos and set video details (titles, descriptions, thumbnails) on the owner's own channel. It does not access or collect data about any other users.

How data is stored

Authorization tokens are stored locally on the owner's private computer and are never shared with third parties. No personal data is sold or transferred.

Google services

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
